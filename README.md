## О проекте / About the project

Этот проект — моя персональная рефлексия о пути в веб-разработке, оформленная в виде веб-страницы. Каждая карточка представляет собой историю об одном из этапов обучения на курсе "Веб-разработчик". Здесь я не только делюсь своими мыслями и чувствами, но и демонстрирую технические навыки, полученные за время учёбы.

**This project is my personal reflection on the journey into web development, designed as a web page. Each card tells a story about a specific stage of learning in the "Web Developer" course. Here, I not only share my thoughts and feelings but also demonstrate the technical skills acquired during my studies.**

## Технологии / Technologies

- **Адаптивная вёрстка (Responsive Layout)**: Использование `clamp()`, `@container` и медиавыражений для корректного отображения на любых устройствах.
- **CSS Flexbox и Grid**: Для построения гибких и предсказуемых макетов карточек и кнопок.
- **CSS-фильтры / CSS Filters**: Применение разнообразных фильтров (`sepia`, `blur`, `invert` и др.) к изображениям для создания уникального настроения каждой карточки.
- **CSS-анимация / CSS Animations**:
  - Плавное изменение цвета и размера иконки лайка (сердца) при наведении, нажатии и клике (`scale`, `fill`).
  - Анимация «заливки» для кнопок через псевдоэлемент `::before` и `transform: translateX`.
  - Эффект `mix-blend-mode: difference` для динамического изменения цвета текста и иконок при наведении.
- **Интерактивность / Interactivity**: Модальное окно (`<dialog>`), появление искр при «лайке» карточки.
- **БЭМ (BEM)**: Структурированная организация классов CSS.

## Что было сделано / What was done

1.  **Вёрстка карточек**: Свёрстаны карточки-воспоминания, каждая с уникальным заголовком, изображением и текстом.
2.  **Стилизация**: Проработаны общие и компонентные стили, создана система переменных CSS для удобства поддержки.
3.  **Кнопки с анимацией**: Реализованы нестандартные кнопки с плавной «заливкой» фона при наведении, используя `::before`, `transform` и `transition`. Цвет текста и иконок меняется синхронно с использованием `mix-blend-mode: difference`.
4.  **Интерактивные иконки**: Создана анимированная иконка «лайка» с изменением цвета контура, основного тела и сердцевины, а также с анимацией искр при клике.
5.  **Модальное окно**: Добавлено модальное окно (`<dialog>`) для имитации сохранения «дискеты» с последней карточки.
6.  **Адаптивность**: Страница корректно перестраивается на всех устройствах: от мобильных телефонов до широкоэкранных мониторов.
